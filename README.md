# Wallet App

Aplicación web progresiva (PWA) para gestionar ingresos, gastos y metas de ahorro, desarrollada con HTML, CSS, JavaScript y IndexedDB.

## 🚀 Características principales

- Registro de ingresos y gastos con etiquetas y fecha.
- Visualización de gráficos dinámicos (Chart.js) para:
    - Ingresos vs Gastos.
    - Gastos por categoría.
    - Progreso de metas de ahorro.
- Gestión de metas de ahorro con seguimiento gráfico.
- Interfaz con tabs y FAB dinámico para abrir modales según la sección activa.
- Persistencia de datos en IndexedDB, incluso sin conexión.
- Diseño responsive y estilo moderno.
- Instalable en mobile desde el navegador.

## 🛠️ Tecnologías utilizadas

- HTML y CSS para la estructura y estilos.
- JavaScript para la lógica de la aplicación.
- IndexedDB para almacenamiento local persistente.
- Chart.js para gráficos interactivos.

## ⚙️ Instalación y uso

- Clonar el repositorio:
- git clone https://github.com/LuisPaisio/wallet-pwa.git
- Abrir index.html en el navegador.
- Crear ingresos, gastos y metas desde los modales.
- Visualizar gráficos y progreso en cada sección.
